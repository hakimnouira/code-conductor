# Code Conductor Web Command Center

A local-first React dashboard for the existing Code Conductor FastAPI backend. This is an additional interface; it does not replace the VS Code extension or backend.

## Run on Windows

Prerequisites: Node.js 20+, npm, and the Code Conductor backend configured using the root README.

1. Start the backend using the existing root setup instructions.
2. In a second PowerShell terminal:
   ```powershell
   cd web
   npm install
   npm run dev
   ```
3. Open http://127.0.0.1:5173.
4. Open **Connections & settings**, enter the local backend URL and bearer token generated by the backend, then select **Save & connect**.
5. Enter the absolute path to the project you want the agents to work in. The backend workspace policy still applies.

## Included

- Live backend health and agent availability.
- Task submission with the existing task endpoint and a real SSE event stream.
- Explicit plan preview using `POST /orchestrator/plan`; the UI labels the plan as a preview, not an executing workflow.
- Git status refresh and a manual allowlisted test-run action.
- Responsive dark command-center UI, reduced-motion support, and a clear activity timeline.

## Security notes

The bearer token is held in this tab's `sessionStorage`, not persisted in local storage. Clear it in Settings when finished. Keep the backend bound to localhost; do not expose it directly to the public internet.

## Build

```powershell
npm run build
```

The static build is emitted to `web/dist`. This milestone does not yet add a production web-server route to FastAPI or a remote multi-user deployment.
